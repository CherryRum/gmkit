# 扩展包

GMKit 的文档目录允许后续增加独立工具包，例如日期、节假日、农历或其他通用能力。当前页面只定义接入方式，不声明这些扩展已经发布。

扩展包应保持独立制品坐标，不强迫核心算法用户下载无关依赖。接入文档门户时至少需要：

1. 在 `catalog/packages.json` 登记包名、制品坐标、当前版本、tag 前缀、指南入口和 API 生成器。
2. 提供安装说明、最小可验证示例、公开 API 文档和错误边界。
3. 固定测试命令，并在文档 CI 中运行；需要外部数据源时记录来源、版本和更新时间。
4. 为独立版本 tag 生成不可变 API 快照，不覆盖其他包的历史文档。
5. 明确时区、历法、数据更新、许可证或第三方服务边界，不使用无法验证的准确性承诺。

更完整的发布和维护要求见 [项目维护](/maintenance/)。
