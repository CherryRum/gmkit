# 协议与标准

本节记录实现依据、协议字段和验证证据。通过单元测试或互操作测试不等同于通过密码产品认证，也不能推出未测试环境、未覆盖参数或第三方版本中的安全性。

## 证据层级

1. **源码与单元测试**证明当前实现的已覆盖行为。
2. **外部标准固定向量**证明特定输入与权威预期一致。
3. **仓库共享向量**证明 Java 与 TypeScript 对已登记协议字段保持一致。
4. **第三方 fixture**证明固定依赖版本与固定场景能够互操作。
5. **认证或审计**必须由对应机构或独立过程提供，不能由前四类证据替代。

根目录 `vectors/interop.json` 主要用于 Java 与 TypeScript 的协议边界对齐。只有明确标注外部标准来源的条目才能作为对应标准的固定参考。
