请求示例
curl -X POST "https://api.gmkit.dev/v1/sm4/encrypt" \ -H "Content-Type: application/json" \ -d {"key":"0123456789ABCDEFFEDCBA9876543210","mode":"CBC","iv":"00000000000000000000000000000000","data":"hello"}
Sm4Request req = new Sm4Request(); req.setMode("CBC"); req.setKey("012345..."); req.setIv("0000...");
await client.sm4.encrypt({ mode: "CBC", key, iv, data });
响应示例
{ "code": 0, "message": "success", "data": { "result": "示例输出结果", "requestId": "req_demo_001" } }

参数说明

参数说明
keySM4 对称密钥
iv初始化向量
mode分组模式
padding填充方式
data待处理数据

算法说明

SM4 是国密 128 bit 分组密码算法，适合对称加密场景。此页强调“模式选择 + 输入输出格式 + 快速示例”，帮助后续开发把复杂参数拆解得更清晰。

安全提示

• 请妥善保管私钥、主密钥等敏感信息。
• 测试环境和正式环境建议使用不同的密钥材料。
• 批量处理建议配套任务状态、失败重试和审计日志。
