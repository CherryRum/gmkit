关于项目
开源工具平台原型更像正式产品的视觉升级版：首页按分类组织，详情页采用完整工作台布局，便于继续演进为真实前端工程。

更适合开源产品落地的密码工具平台原型

设计落地建议

让原型更像真实产品
1

一级导航按能力域分类

左侧先按“加密解密、摘要哈希、密钥与证书、编码转换、开发调试”等分区，再在内容区展开具体工具。

2

详情页保持统一工作台

每个工具页都保留输入区、输出区、右侧 API / 说明区，方便真实工程组件化。

3

文案收敛、避免过度堆叠

减少大段描述，保持页面留白，让视觉更接近正式产品。

4

适配后续 Vue / React 演进

结构清晰、模块边界明确，可直接作为 Codex 实现目标或前端脚手架的设计基线。
