API 调试

右侧保留轻量示例，便于边看边对照开发

请求示例
curl -X POST "https://api.gmkit.dev/v1/sm2/encrypt" \ -H "Content-Type: application/json" \ -d { "publicKey": "04...", "data": "48656c6c6f", "mode": "C1C3C2", "inputFormat": "hex", "outputFormat": "hex" }
Sm2EncryptRequest req = new Sm2EncryptRequest(); req.setPublicKey("04..."); req.setData("48656c6c6f"); req.setMode("C1C3C2"); Sm2EncryptResponse rsp = client.sm2Encrypt(req);
const rsp = await client.sm2.encrypt({ publicKey: "04...", data: "48656c6c6f", mode: "C1C3C2", inputFormat: "hex" });
响应示例
{ "code": 0, "message": "success", "data": { "result": "示例输出结果", "requestId": "req_demo_001" } }

参数说明

outputFormat输出格式

算法说明

SM2 是国密公钥密码算法，适用于加密解密、数字签名和密钥交换等场景。此页进一步收敛布局，把重点放在输入、输出、动作和 API 说明四个核心区域，更适合作为真实产品界面的基础稿。

安全提示

• 请妥善保管私钥、主密钥等敏感信息。
• 测试环境和正式环境建议使用不同的密钥材料。
• 批量处理建议配套任务状态、失败重试和审计日志。
