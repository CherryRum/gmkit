# Codex Goal：将 GMKit Studio 原型继续提升到更接近正式 SaaS 产品 UI（V4）

## 目标
在 V3 的结构基础上继续提升视觉精致度，让页面更像正式产品设计稿。

## 本轮重点
1. 保留 V3 的左侧一级分类导航结构，不再回退到旧版工具平铺样式。
2. 提升卡片体系：
   - 更细的边框
   - 更柔和的阴影
   - 更统一的圆角
   - 轻微顶部高光
   - 更舒适的留白
3. 提升图标体系：
   - 统一的图标容器尺寸
   - 更细的渐变和状态感
   - 同类模块颜色一致
4. 提升产品感：
   - Hero 区更稳重
   - 顶部栏更像正式 SaaS 工具平台
   - 右侧说明区更像真实产品配置卡片
   - 标签、按钮、输入框更统一
5. 保持页面结构可工程化，便于继续迁移到 Vue3 / React。

## 验收标准
- 首页明显比 V3 更精致
- 左侧导航结构保持正确
- 详情页更像正式产品设计稿
- 页面之间风格统一
- 不出现乱码、文字重叠、组件挤压
