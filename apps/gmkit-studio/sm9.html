API 调试

右侧保留轻量示例，便于边看边对照开发

请求示例
curl -X POST "https://api.gmkit.dev/v1/sm9/sign" \ -H "Content-Type: application/json" \ -d {"id":"alice@example.com","data":"hello world"}
Sm9SignRequest req = new Sm9SignRequest(); req.setId("alice@example.com"); req.setData("hello world");
await client.sm9.sign({ id: "alice@example.com", data: "hello world" });
响应示例
{ "code": 0, "message": "success", "data": { "result": "示例输出结果", "requestId": "req_demo_001" } }

参数说明

参数说明
masterPublicKey主公钥
masterPrivateKey主私钥
id用户标识
data待处理消息
mode操作模式

算法说明

SM9 是国密标识密码算法，支持基于身份的签名、加密和密钥协商。页面在视觉上保持与 SM2 / SM4 一致，但更突出“主密钥”和“用户标识”这两个核心输入维度。

安全提示

• 请妥善保管私钥、主密钥等敏感信息。
• 测试环境和正式环境建议使用不同的密钥材料。
• 批量处理建议配套任务状态、失败重试和审计日志。
