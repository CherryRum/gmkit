API 调试

右侧保留轻量示例，便于边看边对照开发

请求示例
curl -X POST "https://api.gmkit.dev/v1/zuc/encrypt" \ -H "Content-Type: application/json" \ -d {"key":"0011...","iv":"1122...","data":"68656c6c6f"}
ZucRequest req = new ZucRequest(); req.setKey("0011..."); req.setIv("1122...");
await client.zuc.encrypt({ key, iv, data, inputFormat: "hex" });
响应示例
{ "code": 0, "message": "success", "data": { "result": "示例输出结果", "requestId": "req_demo_001" } }

参数说明

参数说明
keyZUC 密钥
iv初始化向量
data待处理数据
operation操作类型

算法说明

ZUC 是面向流式处理场景的序列密码算法。这一版工作台更强调轻量、简洁和正式产品感，同时保留未来扩展“分片处理”“密钥流可视化”“完整性校验结果”的空间。

安全提示

• 请妥善保管私钥、主密钥等敏感信息。
• 测试环境和正式环境建议使用不同的密钥材料。
• 批量处理建议配套任务状态、失败重试和审计日志。
