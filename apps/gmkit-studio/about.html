项目说明
本项目是一套围绕 GMKit 工具能力整理的高保真 HTML 原型，目标是为后续 Vue / React 工程实现、接口接入和组件拆分提供清晰基线。这一版特别强化了“左侧一级分类”和“详情页正式产品感”。

原型目标

从视觉、结构到工程实现都可落地
A

统一风格

首页、工具页、辅助页都保持一致的布局和色彩体系。

B

清晰分类

左侧按能力域分组，更接近正式产品的信息组织方式。

C

工具工作台

算法页统一使用输入区、输出区、右侧说明区的工作台形式。

D

可工程化

结构清晰、模块边界明确，后续便于拆成真实前端项目。
